mailto: links

Each link should open the mail program (xdg-open, or the one in MAIL_CLIENT) with the fields shown, and Chimera should stay on this page. Without a mail program, a short page shows the address instead.

1. Plain address

mailto:someone@example.com

Expected: a new message to someone@example.com.

2. Subject and body

subject and two-line body

Expected: subject "Hello from Chimera", body on two lines. (With MAIL_CLIENT set, only the address is passed.)

3. Danish letters in the subject

subject Rødgrød med fløde

Expected: subject "Rødgrød med fløde" (sent %-encoded as UTF-8).

4. Several recipients and Cc

two recipients, one Cc

Expected: To one@example.com and two@example.com, Cc three@example.com.

5. Unusual but valid addresses

first.last+tag@example.com | "quoted name"@example.com

Expected: the address exactly as shown.

6. Typed in the Open dialog

Open (o) and type mailto:someone@example.com.

Expected: as test 1.

7. No mail program

Start Chimera with MAIL_CLIENT=nosuchmailer chimera and click test 1.

Expected: a page saying the mail program nosuchmailer was not found, with the address.
