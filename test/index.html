Chimera test pages

Each page says what to expect. Some send forms to httpbin.org or load pictures from the net; the rest work offline.

  • charset-utf8.html - UTF-8 page without a charset declaration
  • charset-cp1252.html - the same text in windows-1252
  • forms-test.html - Enter submits, UTF-8 form data, isindex, gopher search
  • forms-extended.html - checkboxes, radio buttons, selects, text area, hidden, reset, two submit buttons
  • password-test.html - password fields, maxlength, pasting, adjacent links
  • mailto-test.html - mailto: links
  • rowspan-test.html - rowspan and borders
  • tables-extended.html - colspan, nested tables, widths, padding, empty cells
